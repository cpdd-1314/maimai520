微信小商店 —— 推送到 GitHub 图文教程（约 5 分钟）
============================================================

【为什么要在“你自己的电脑”上推送】
本项目的开发环境网络无法直连 github.com（已被网络策略阻断，已实测）。
GitHub 只接受从能访问它的网络推送，所以在你自己电脑上执行这一步最稳妥。

你只需要：一台能上网的电脑（Windows / Mac 都行）+ 一个 GitHub 账号（免费）。

------------------------------------------------------------
第 0 步：安装必要工具（只做一次）
------------------------------------------------------------
• Windows：
  1) 安装 Git：https://git-scm.com/download/win 一路“下一步”
  2) 安装完成后，开始菜单搜“Git Bash”并打开（下面命令都在 Git Bash 里跑）
• Mac：
  1) 打开“终端”，执行一次：  xcode-select --install
  2) 装 Homebrew（可选）后执行：  brew install git
  验证：  git --version   能输出版本号即可

------------------------------------------------------------
第 1 步：在 GitHub 上建一个空仓库（2 分钟）
------------------------------------------------------------
1. 浏览器登录 https://github.com
2. 右上角头像旁点“+” → 选“New repository”
3. Repository name 填：  maimai520
4. 可见性选：  Private   （私有，只有你能看）
5. 不要勾选 “Add a README file”（保持空仓库）
6. 点绿色按钮 Create repository
7. 创建后页面会显示仓库地址（HTTPS 那行），形如：
      https://github.com/cpdd-1314/maimai520.git
  这个地址已内置在推送脚本里，你不用手动填（想确认就直接比对是否一致）。

------------------------------------------------------------
第 2 步：解压代码包并推送（2 分钟）
------------------------------------------------------------
1. 下载并解压  wxshop-github.zip
   （里面含全部代码、本教程、push-to-github.sh）
2. 打开终端/Git Bash，进入解压后的文件夹，执行（什么都不用填）：

      cd 拖入文件夹路径
      bash push-to-github.sh

   脚本已内置推送地址：https://github.com/cpdd-1314/maimai520.git
   （若你想改推别的仓库，可加参数：bash push-to-github.sh 你的仓库地址）

3. 首次推送会要求登录 GitHub，两种方式任选：
   A. 浏览器登录：页面提示时，把一次性代码输到
      https://github.com/login/device  后回车授权
   B. 或执行 gh auth login 按提示登录
4. 看到 ✅ 推送完成！ 就成功了。刷新 GitHub 仓库页面，
   应能看到 server.js、src/、views/、render.yaml 等文件。

------------------------------------------------------------
第 3 步（可选但重要）：把网站真正“跑起来”
------------------------------------------------------------
⚠️ 注意：代码上 GitHub 只是存好了，买家还不能访问网站。
要让网站上线，二选一（详见代码包里的 README.md 第四节）：

A. Render（推荐，简单）：
   1) 注册 https://render.com
   2) New → Blueprint → 连接你的 GitHub 仓库，会自动读取 render.yaml
   3) 选 Starter 计划（约 $7/月，数据持久、不休眠）
      注意：免费版不支持持久磁盘，重启会清空订单和商品图片！
   4) 填环境变量：管理员初始密码、微信参数（个人收款码模式可不填）
   5) Deploy，完成后拿到 https://你的服务.onrender.com 域名

B. 国内云服务器 VPS：
   代码里已有 .github/workflows/deploy.yml，按 README 配置自动部署

------------------------------------------------------------
常见问题
------------------------------------------------------------
Q: 推送报错 “Repository not found”？
A: 检查第 1 步是否已建好仓库、地址里的用户名是否和地址一致。

Q: 提示输入用户名密码但进不去？
A: GitHub 已不支持密码推送，请走 gh 登录（脚本提示方式 A/B），
   或用“Personal access token”当密码：GitHub → Settings →
   Developer settings → Personal access tokens → 生成（勾选 repo 权限）。

Q: 本地没有装 Git 也能推吗？
A: 不行，第 0 步必须装。装好 git --version 有输出即可。

Q: 我已经有这个网站的其他改动想一起传？
A: 重新执行第 2 步的命令即可，脚本会自动提交新改动再推送。
