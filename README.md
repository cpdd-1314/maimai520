# 微信小商店

一个可自己上传商品售卖的小网站：买家下单 → 微信扫码付款 → 生成订单 → 管理员后台查看与管理。

支持**两种收款方式**，后台一键切换：

| 模式 | 说明 | 门槛 |
|---|---|---|
| **个人收款码**（默认推荐先用的） | 你在后台上传自己的微信收款码；买家扫码付款后上传支付截图；你在后台点「确认收款」 | 零门槛，有微信就能用 |
| **微信支付官方 API** | 系统为每笔订单生成动态支付二维码，微信回调自动把订单标记为已付款 | 需要微信支付商户号（企业/个体工商户） |

> 💡 **系统默认就是「个人收款码」模式**。如果你还没有、或暂时申请不下来微信支付商户号（官方 API 需要营业执照），直接用默认模式即可开卖；等以后办下资质，随时在后台切回官方 API，商品和订单数据不受影响。

---

## 一、本地运行

```bash
npm install
cp .env.example .env     # 按需修改（本地可不填微信参数）
node server.js           # 打开 http://localhost:3000
```

首次启动会自动创建管理员（默认 `admin` / `admin123456`，可用环境变量 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 改），**登录后请立即修改密码**。

- 前台：`/`
- 后台：`/admin`

## 二、两种收款模式怎么用

### 模式 A：个人收款码（今天就能开卖）

1. 后台 → **设置** → 收款模式选「个人收款码」。
2. 上传你的微信收款码图片（微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存收款码）。
3. 买家下单后看到你的收款码，扫码付款，然后上传支付截图。
4. 你在 **订单管理** 里看到状态为「待确认收款」的订单，点开截图核对，确认无误后点 **确认收款** → 订单变「已付款」。

### 模式 B：微信支付官方 API（自动确认，需商户资质）

1. 备齐商户参数（见下一节），在部署环境配置 `WX_*` 环境变量。
2. 后台 → **设置** → 收款模式选「微信支付官方 API」。
3. 买家下单后系统自动生成动态二维码，付款成功后微信回调，订单自动变「已付款」。

> 若还没商户号，**先用模式 A**；等资质下来再切模式 B，商品和订单数据都不受影响。

## 三、微信支付官方 API 参数哪里来（模式 B 才需要）

> ⚠️ **硬门槛**：个人主体（无营业执照）申请不了微信支付商户号，必须是**企业或个体工商户**。个体工商户执照通常可在当地市场监管局线上办理。

**第 1 步：注册商户号** —— 打开 <https://pay.weixin.qq.com>
1. 点「注册微信支付商户号」→ 微信扫码创建申请单（该微信成为超级管理员）。
2. 填写：营业执照、法人身份证、经营类目、结算银行账户（个体户可用法人银行卡）。
3. 账户验证二选一：法人微信扫码确认，或等平台往对公账户打一笔小额款后回填金额。
4. 审核 1–2 个工作日 → 在线签约 → 得到 **商户号 mchid**。

**第 2 步：取开发参数**

| 参数 | 环境变量 | 在哪里拿 |
|---|---|---|
| appid | `WX_APPID` | 微信公众平台 <https://mp.weixin.qq.com> 复制 AppID → 回商户平台【产品中心】→【AppID 账号管理】关联，需超管微信确认 |
| 商户号 | `WX_MCHID` | 上一步注册得到 |
| APIv3 密钥 | `WX_APIV3_KEY` | 【账户中心】→【API 安全】→ 设置 APIv3 密钥，32 位字母数字。**设置后无法再查看，只能重设，务必先存好** |
| 商户证书序列号 | `WX_SERIAL_NO` | 【API 安全】→ 申请商户 API 证书，证书信息里的 40 位序列号 |
| 商户私钥 | `WX_PRIVATE_KEY` | 申请证书时用官方「证书工具」生成的 `apiclient_key.pem` 内容（多行请用 `\n` 连接）；也可改用 `WX_PRIVATE_KEY_FILE` 指定文件路径 |
| 回调地址 | `WX_NOTIFY_URL` | 你的域名 + `/pay/notify`，例如 `https://你的服务.onrender.com/pay/notify`。**必须是公网 HTTPS** |

> 🔒 商户私钥一旦丢失无法找回，只能重新申请。**绝不要**把私钥发到聊天窗口、工单或提交进 Git 仓库。
> 💡 官方还有「微信支付公钥」可替代平台证书（无过期时间，更好维护）；本项目的回调验签已实现自动下载并缓存平台证书，无需手动配置。

## 四、部署上线

### 重要：GitHub 不运行网站

GitHub 只是**代码仓库**。要让买家能打开网站、微信能回调通知，必须有**运行中的服务器**。
标准做法：代码推到 GitHub → 托管平台自动拉取并部署。**两者都要，缺一不可。**

### 方案 1：Render（推荐，最简单）

> ⚠️ **Render 免费版不支持持久磁盘**，订单、商品、上传的图片会在重启/休眠时**全部丢失**，且 15 分钟无流量就休眠（买家打开要等约 1 分钟冷启动）。**真卖货请用 Starter（约 $7/月）。**

1. 把代码推到 GitHub 仓库（见第五节）。
2. 登录 <https://render.com> → **New** → **Blueprint** → 关联你的 GitHub 仓库，会自动读取仓库里的 `render.yaml`。
3. 在 Environment 里填写标了 `sync: false` 的变量（管理员初始密码、微信参数）。
4. 点 Deploy。部署完成后会给你一个 `https://xxx.onrender.com` 域名。
5. 把这个域名填进 `WX_NOTIFY_URL`（模式 B 需要：`https://xxx.onrender.com/pay/notify`）。
6. 之后每次 `git push`，Render 会自动重新部署。

想省钱只想先试玩：把 `render.yaml` 里 `plan: starter` 改成 `plan: free`，并**删掉整个 `disk:` 段**，同时把 `DATA_DIR` 改成 `./data`。但记住数据会丢。

### 方案 2：自有 VPS（阿里云/腾讯云轻量，约 ¥24/月起）

磁盘天然持久、国内访问快、不休眠。仓库里已附 `.github/workflows/deploy.yml`：
1. 服务器装好 Node 18+ 和 pm2。
2. 在 GitHub 仓库 Settings → Secrets 里加 `HOST`、`USERNAME`、`SSH_KEY`、`APP_DIR`。
3. 往 `main` 分支 push，Actions 会自动 rsync 代码、装依赖并 `pm2` 重启服务。
4. 用 Nginx 反向代理 + 申请 SSL 证书（微信回调要求 HTTPS）。

## 五、目录结构

```
server.js              入口
src/
  config.js            环境变量集中配置
  db.js                JSON 文件数据存储（商品/订单/管理员/设置）
  auth.js              登录校验（内置 scrypt 做密码哈希）
  upload.js            图片上传（限图片类型、≤5MB、随机文件名）
  wechatpay.js         微信支付 APIv3：签名、Native 下单、回调验签 + AES 解密
  util.js              金额格式化、订单号、状态文案
  routes/
    shop.js            前台：商品列表、详情、下单
    pay.js             支付：动态/静态二维码、上传截图、状态轮询、微信回调
    admin.js           后台：登录、仪表盘、商品 CRUD、订单、设置
views/                 EJS 模板（shop/ 前台，admin/ 后台）
public/css/style.css   样式
data/                  运行时数据（db.json + uploads/），已在 .gitignore 中
```

## 六、安全说明

- 管理员密码用 `scrypt` 加盐哈希存储，会话走 httpOnly cookie。
- 微信商户私钥、APIv3 密钥**只走环境变量**，不写入数据库、不进 Git。
- 支付回调**先验签再解密**，并校验通知金额与订单金额一致，防伪造「假支付」；已付款订单做幂等处理，重复通知不会重复记账。
- 上传文件校验为图片类型、限制 5MB、随机文件名，避免路径穿越。
- `.gitignore` 已排除 `node_modules/`、`data/`、`.env`、证书私钥文件。

## 七、常见问题

**Q：没有营业执照，能收款吗？**
能——用「个人收款码」模式，不需要任何审批。缺点是得手动确认每一笔。

**Q：买家付款后页面没跳转？**
官方 API 模式靠微信回调 + 前端轮询（每 3 秒）自动跳转；个人收款码模式在你点「确认收款」后自动跳转。若长时间没反应，检查 `WX_NOTIFY_URL` 是否为公网 HTTPS 且能访问。

**Q：订单数据存在哪？会丢吗？**
存在 `DATA_DIR` 指向的目录（默认 `./data/db.json`）。Render 免费版会因重启丢失；Starter + 持久磁盘或自有 VPS 不会。建议定期备份 `data/` 目录。
